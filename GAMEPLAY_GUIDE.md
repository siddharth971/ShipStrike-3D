# ShipStrike-3D — Complete Getting Started Guide

## Step 1 — Access the Game

1. **Open your browser** (Chrome or Firefox recommended)
2. **Go to** `http://localhost:5173` (or your deployment URL)
3. **The game loads instantly** in your browser. No download needed!
4. **You will see** a login screen with username field and character creation

---

## Step 2 — Login / Create Account

### Guest Play (No Account)

- Type any username in the name field
- Click "Play as Guest"
- You can play immediately, but progress won't be saved

### Create Account (Recommended)

1. Click "Create Account"
2. Enter username and email
3. Create a password
4. Your account saves all progress:
   - ✅ Ship levels
   - ✅ Gold and XP
   - ✅ Ship upgrades
   - ✅ Friends list
   - ✅ Clan membership

---

## Step 3 — Select Your Starting Ship

### 3 Ship Types Available

#### ⛵ **Sloop** (Level 1)

- **HP**: 150 HP
- **Cannons**: 1 cannon/side
- **Speed**: 45 units/sec
- **Crew Size**: 1-2 players
- **Best for**: Solo play & learning
- **Fastest accelerating ship**

#### 🚢 **Frigate** (Level 9)

- **HP**: 250 HP
- **Cannons**: 2 cannons/side
- **Speed**: 35 units/sec
- **Crew Size**: 2-3 players
- **Best for**: Balanced PvP combat
- **Best all-around versatility**

#### ⚔️ **Warship** (Level 30)

- **HP**: 400 HP
- **Cannons**: 4 cannons/side
- **Speed**: 25 units/sec
- **Crew Size**: 3-5 players
- **Best for**: Full crew fleet battles
- **Heavy firepower but slower**

**Tip**: Start with Sloop to learn controls. Earn XP and gold to unlock Frigate at Level 9!

## Step 4 — Select Game Mode & Join Server

### Available Game Modes

#### 🏴 **Team Flags** (PvP Combat)

- **Players**: Up to 60 per match
- **Objective**: Sink enemy ships, capture objectives
- **Teams**: Red vs Blue (assigned automatically)
- **Rewards**: Gold per kill, XP for damage, team bonuses
- **Best for**: Intense naval combat & teamwork

#### 💰 **Trader Mode** (PvE Economy)

- **Players**: Up to 90 per match
- **Objective**: Trade goods, earn profits, fight rivals
- **Gameplay**:
  - Buy goods at islands (low price)
  - Sell at other islands (high price)
  - Optional: Pirate other traders for quick gold
- **Best for**: Casual play, relaxed economy gameplay

#### ⚓ **Classic PvP** (Free-for-All)

- **Players**: Up to 100 per match
- **Objective**: Be the last ship standing
- **No teams**: Every ship for itself
- **Best for**: High-risk, high-reward combat

### Joining a Server

1. **Select game mode** (Team Flags, Trader, or Classic)
2. **See server list**:
   - Shows player count
   - Shows ping (lower = better, <100ms ideal)
   - Shows match status (Starting / In Progress)
3. **Pick a server** with <100ms ping and 20+ players for best experience
4. **Play with Friends**: Enter friend's Ship Code to join their crew
5. **Click "Join"** — You spawn on your ship immediately!

## Step 5 — Basic Controls & Movement

### Sailor Movement (On Deck)

| Key         | Action                              |
| ----------- | ----------------------------------- |
| **W A S D** | Move sailor forward/left/back/right |
| **Space**   | Jump                                |
| **Mouse**   | Look around / Aim cannons           |
| **F**       | Interact with ship parts            |
| **Click**   | Fire cannon (when manned)           |
| **Esc**     | Open/close menu                     |
| **Tab**     | Open scoreboard & stats             |

### Ship Control (At Helm)

| Control            | Action                             |
| ------------------ | ---------------------------------- |
| **Hold F at Helm** | Grab steering wheel                |
| **A / D**          | Steer left / right                 |
| **W**              | Increase throttle (faster speed)   |
| **S**              | Decrease throttle (slower/reverse) |
| **Walk away**      | Release helm (AI bot takes over)   |

### Sail Management (At Sails)

| Control                                                   | Action             |
| --------------------------------------------------------- | ------------------ |
| **Hold F at Sails**                                       | Grab sail controls |
| **A / D**                                                 | Adjust sail angle  |
| **Watch flags**: When sails stop flapping = optimal speed |
| **Walk away**                                             | Release sails      |

## 6 Cannonball Types

### ⚪ **Normal Ball**

- **Damage**: 10 dmg (free)
- **Speed**: Fast
- **Type**: All-purpose
- **Best for**: General combat

### 💙 **Light Ball**

- **Damage**: 4 dmg
- **Speed**: Very fast
- **Type**: Rapid-fire
- **Best for**: Spraying enemy ships

### 🟠 **Heavy Ball**

- **Damage**: 22 dmg
- **Speed**: Slow
- **Type**: Heavy impact
- **Best for**: Finishing shots, dealing heavy damage

### 🔴 **Grape Shot**

- **Damage**: 20 dmg (spread effect)
- **Speed**: Medium
- **Type**: Splash / Area damage
- **Best for**: Hitting sailors on enemy decks, close-range

### 🟣 **Sniper Shot**

- **Damage**: 19 dmg
- **Speed**: Very fast, ultra-range
- **Type**: Long-distance
- **Best for**: Sniping distant ships

### 🟢 **Chain Shot**

- **Damage**: Slows / disables
- **Speed**: Medium
- **Type**: CC (crowd control)
- **Best for**: Disabling masts, slowing enemy maneuvers

### Switching Cannonball Types (At Cannon)

| Key       | Action                          |
| --------- | ------------------------------- |
| **A**     | Previous ball type              |
| **D**     | Next ball type                  |
| **E**     | Quick alternate (Heavy ↔ Grape) |
| **Click** | Fire selected ball              |

## Combat Basics

### Cannon Combat

#### Aiming

1. Walk to cannon
2. Press **F** to man it
3. **Mouse movement** = aim up/down/left/right
4. **Click** = fire

#### Broadside Formation (Advanced)

- Position ship **perpendicular** to enemy (sideways)
- All cannons can fire simultaneously
- Bow-first positioning = only 1 forward cannon
- **Broadside = 4x more damage output!**

### Melee Combat (Sailor-to-Sailor)

| Weapon          | Damage | Range        | Best For             |
| --------------- | ------ | ------------ | -------------------- |
| **Sword**       | 15 dmg | Close (2m)   | 1v1 fights on deck   |
| **Musket**      | 20 dmg | Medium (20m) | Ranged player combat |
| **Empty Hands** | 5 dmg  | Close (1m)   | Emergency defense    |

## Game Mode Details

### Team Flags Mode

1. **You spawn** on Red or Blue team
2. **Team ships** show friendly marker (don't fire!)
3. **Enemy ships** show red/blue hostiles markers
4. **Coordinate with crew**:
   - 1 player: Helm (steering)
   - 1 player: Sails (speed management)
   - 1-2 players: Cannons (firepower)
5. **Up to 60 players** in fleet battles
6. **Win condition**: Sink most enemy ships OR control objectives

### Trader Mode

1. **Sail to islands**, find Trader NPCs
2. **Buy goods** at low prices (e.g., Wheat: 50 gold)
3. **Sail to another island**, sell at profit (Wheat: 150 gold)
4. **Routes available**:
   - London → Paris (Cloth, Wine)
   - Port Royal → Tortuga (Cargo, Spices)
   - Shanghai → Tokyo (Silk, Tea)
5. **Danger**: Other players will attack you for cargo!
6. **Pirate option**: Attack traders, steal cargo for quick gold
7. **Up to 90 players** per server
8. **Bigger servers** = more trading routes, more competition

## Beginner Tips & Tricks

### 🎯 Learn the Basics

- **Use Helper Bot first**: Let it steer/fire while you explore and learn
- **Practice cannon aiming** in low-risk situations
- **Master the minimap**: Shows all nearby ships in real-time

### 🗺️ Map Awareness

- **Watch minimap constantly** — spots enemies before they see you
- **Use islands as cover** — sail behind them to lose pursuers
- **Beaching**: If sinking, beach near an island to stay afloat longer

### 💰 Gold Farming

- **Pick on weakened ships**: Finish off low-HP ships for easy gold
- **Target lone sailors**: 1v1 fights are easier than crew vs crew
- **Collect damage**: Even hits that don't sink ships reward gold

### ⚡ Energy Management

- **Watch throttle**: Higher speed = lower turning ability
- **Balance speed & maneuverability**: Medium speed is often best
- **Reverse to turn tighter**: Slow down, then reverse to pivot

## Advanced Strategy

### ⚓ Broadside Positioning

- Ship **facing enemy = 1 cannon**
- Ship **perpendicular (sideways) = 4 cannons**
- **Always maneuver for broadside advantage**
- Pro move: Sail parallel, unleash full broadside, then turn away

### 💨 Wind Mastery

- **Watch sail flags** — they show wind direction
- **Adjust sails** so they stop flapping = max speed boost
- **Sail into wind** = slower but tighter turning
- **Sail with wind** = faster but wider turning radius
- Advanced: **Use wind to cut off enemies** — position upwind so they can't escape

### 🎯 Sniper Shots at Range

- **Use Sniper Shot** balls (unlock at Level 10)
- **Faster and farther** than normal balls
- **Lead your target**: Aim ahead of moving enemies
- **Pro sniper**: Can kill ships from across the map

### 🍇 Grape Shot for Close Range

- **Switch to Grape Shot** when enemies are near
- **Massive splash damage** to sailors on deck
- **Excellent for crew combat** — hits multiple sailors at once
- **Use when ramming enemies**

### 🔗 Chain Shot Disable Tactic

- **Hit enemy masts** with chain shot to slow them
- **Disabled masts** = ship can't turn efficiently
- **Close in** while they're slowed, finish with heavy balls
- **Pro technique**: Sniper shot (range) → Chain shot (disable) → Heavy ball (finish)

### 👥 Crew Role Assignment

- **Helm Captain**: Steers, calls out targets, manages positioning
- **Sail Master**: Manages sails, adjusts for wind, maximizes speed
- **Cannon Master(s)**: Focus fire on targets, switch ammo types as needed
- **Deck Sergeant**: Mans muskets, defends against boarding, repairs damage

**With organized crew:** 4-5x more effective than solo players!

## Troubleshooting

### Game Won't Load

- Clear browser cache (Ctrl+Shift+Delete)
- Try different browser (Chrome/Firefox)
- Check connection to server (confirm port 3000 is running)

### Lag or High Ping

- Close other browser tabs
- Check WiFi signal strength
- Join server with lower player count
- Enable "Low Graphics Mode" in settings

### Ship Takes Damage Instantly

- Get behind island cover
- Sail perpendicular to enemy fire
- Use Helper Bot to steer while you control cannons
- Repair at friendly port _(if available)_

### Can't Hear Friends in Chat

- Check Discord settings (or in-game voice)
- Unmute your microphone
- Test microphone in browser settings
